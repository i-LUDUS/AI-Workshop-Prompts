# Gestructureerde prompt

- **Categorie:** Prompt engineering
- **Techniek:** Gestructureerde prompt
- **Versie:** 1.0
- **Status:** Workshopvoorbeeld
- **Prompttaal:** nl
- **Uitvoertaal:** nl

## Doel
Demonstreren hoe gestructureerde prompt de instructie aan een AI-model vormgeeft.

## Prompt

```text
Analyseer de volgende AI-use-case: {{usecase}}. Gebruik exact deze structuur: 1. Probleem, 2. Doel, 3. Stakeholders, 4. Data, 5. Technologie, 6. Risico's, 7. KPI's, 8. Aanbeveling.
```

## Gebruik
Vervang eventuele `{{variabelen}}` door je eigen gegevens. Kopieer de prompt naar je AI-toepassing en controleer de uitkomst kritisch.

## Evaluatie
Controleer relevantie, juistheid, volledigheid en naleving van de instructies.
