# Decompositie

- **Categorie:** Prompt engineering
- **Techniek:** Decompositie
- **Versie:** 1.0
- **Status:** Workshopvoorbeeld
- **Prompttaal:** nl
- **Uitvoertaal:** nl

## Doel
Demonstreren hoe decompositie de instructie aan een AI-model vormgeeft.

## Prompt

```text
Onderzoek dit proces: {{proces}}. Fase 1: beschrijf de huidige werking. Fase 2: identificeer knelpunten. Fase 3: stel AI-oplossingen voor. Geef daarna een prioriteitenlijst met motivatie.
```

## Gebruik
Vervang eventuele `{{variabelen}}` door je eigen gegevens. Kopieer de prompt naar je AI-toepassing en controleer de uitkomst kritisch.

## Evaluatie
Controleer relevantie, juistheid, volledigheid en naleving van de instructies.
