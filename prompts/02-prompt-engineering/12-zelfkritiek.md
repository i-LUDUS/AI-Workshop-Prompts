# Zelfkritiek

- **Categorie:** Prompt engineering
- **Techniek:** Zelfkritiek
- **Versie:** 1.0
- **Status:** Workshopvoorbeeld
- **Prompttaal:** nl
- **Uitvoertaal:** nl

## Doel
Demonstreren hoe zelfkritiek de instructie aan een AI-model vormgeeft.

## Prompt

```text
Stel een oplossing voor dit probleem voor: {{probleem}}. Beoordeel je voorstel vervolgens op haalbaarheid, kosten, privacy en impact. Benoem zwakke punten en presenteer een verbeterde versie.
```

## Gebruik
Vervang eventuele `{{variabelen}}` door je eigen gegevens. Kopieer de prompt naar je AI-toepassing en controleer de uitkomst kritisch.

## Evaluatie
Controleer relevantie, juistheid, volledigheid en naleving van de instructies.
