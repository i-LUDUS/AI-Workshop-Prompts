# Zero-shot

- **Categorie:** Prompt engineering
- **Techniek:** Zero-shot
- **Versie:** 1.0
- **Status:** Workshopvoorbeeld
- **Prompttaal:** nl
- **Uitvoertaal:** nl

## Doel
Demonstreren hoe zero-shot de instructie aan een AI-model vormgeeft.

## Prompt

```text
Leg in maximaal 150 woorden uit wat generatieve AI is voor een manager zonder technische achtergrond.
```

## Gebruik
Vervang eventuele `{{variabelen}}` door je eigen gegevens. Kopieer de prompt naar je AI-toepassing en controleer de uitkomst kritisch.

## Evaluatie
Controleer relevantie, juistheid, volledigheid en naleving van de instructies.
