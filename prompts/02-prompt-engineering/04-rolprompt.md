# Rolprompt

- **Categorie:** Prompt engineering
- **Techniek:** Rolprompt
- **Versie:** 1.0
- **Status:** Workshopvoorbeeld
- **Prompttaal:** nl
- **Uitvoertaal:** nl

## Doel
Demonstreren hoe rolprompt de instructie aan een AI-model vormgeeft.

## Prompt

```text
Je bent een ervaren Lean Six Sigma Black Belt. Analyseer het volgende proces en benoem de belangrijkste vormen van verspilling: {{procesbeschrijving}}.
```

## Gebruik
Vervang eventuele `{{variabelen}}` door je eigen gegevens. Kopieer de prompt naar je AI-toepassing en controleer de uitkomst kritisch.

## Evaluatie
Controleer relevantie, juistheid, volledigheid en naleving van de instructies.
